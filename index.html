\U0001F4E1 Publicar e atualizar (GitHub Pages)

  1. Publicar: suba a pasta no GitHub, vá em Settings → Pages, escolha branch main / root e salve. Em ~1 min o link seu-usuario.github.io/album-copa-2026 abre o app.
  2. Atualizar nomes: edite o arquivo dados.js (ex.: descomente uma linha do Update Set), depois rode git add . → git commit -m "atualiza" → git push. O site atualiza sozinho.
  3. Suas marcações ficam salvas neste navegador. Para passar de um aparelho a outro, use Backup / Restaurar.
